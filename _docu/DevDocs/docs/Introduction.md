# Introduction
The UseCaseApp is a tool designed for managing PostgreSQL databases via API calls. It supports the basic CRUD functions: Create, Read, Update, and Delete, allowing users to manage database entries directly through the application. This documentation provides a guide on how to utilize the app effectively for database operations.
